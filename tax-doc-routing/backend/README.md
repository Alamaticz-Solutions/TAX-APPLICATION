# Tax Document Routing — Backend

Rust/Axum GraphQL backend for Tax Document Routing, built on the PDS App Framework. The
framework's `appfw_runtime` provides the request pipeline, auth, data-access layer, policy
evaluation and observability; `appfw_provider_postgres` provides the PostgreSQL provider. Both
are consumed as Cargo path dependencies on `../../app-framework`, vendored in this monorepo.

## Layout

| Path | Ownership |
|---|---|
| `src/services/` | Product: routing engine, document store boundary, PDF protection, notifications. |
| `src/handlers/<schema>/<entity>.rs` | Product: custom method implementations; delegate to services. |
| `src/platform/` | Product: thin wiring over `appfw_runtime`. |
| `src/routes/`, `src/schemas/`, `src/handlers/**/generated.rs`, `src/operations/` | Generated by `app_gen` from `.appfw/model/**`. Do not hand-edit; change the model and regenerate. |
| `src/data/`, `src/config/` | Product: orchestration over the framework's `DataAccess` and config loading. |
| `config/generated/` | Generated runtime configuration (flattened model). |
| `product_dist/` | Frontend SPA bundle, built by `cd ../frontend && npm run build`. Served at `/` when `APP_PRODUCT_UI_ENABLED=true`. |

## Feature flags

`default = ["http", "provider-postgres"]`. `mcp` / `kafka` / `sync` are not enabled: this product
runs a single HTTP process against one PostgreSQL data source.

## Run

Run from `backend/` (config is resolved relative to the working directory):

```bash
# database (published on host port 5434 so it can run beside other products)
APP_POSTGRES_HOST_PORT=5434 docker compose -f ../podman-compose.yml up -d postgres

cp .env.example .env          # git-ignored
cargo run -p backend --bin backend     # http://127.0.0.1:8080
```

GraphQL routes are schema-specific: `/tax-routing` (product) and `/system` (framework metadata).

The runtime is built by hand in `src/main.rs` with a large worker stack
(`BACKEND_WORKER_STACK_MIB`, default 128): the read path recurses deeply enough to overflow the
default stack, which shows up as `thread 'tokio-rt-worker' has overflowed its stack`.

## Regenerate after a model change

```bash
# from tax-doc-routing/; on Windows use the rust-appfw container (see the root CLAUDE.md)
scripts/appfw product validate --json
scripts/appfw product generate
scripts/appfw product generate --check --json
cargo check --workspace --all-targets && cargo test --workspace
```
