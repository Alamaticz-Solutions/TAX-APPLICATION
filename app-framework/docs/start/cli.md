# CLI Router

This compatibility page exists because older prompts, downstream repos, and
agent instructions may still reference `docs/start/cli.md`.

For the short first-contact path, use [CLI Quickstart](cli-quickstart.md).
For the full command and JSON contract, use
[CLI Reference](../reference/cli.md).

The canonical command seam is:

```bash
scripts/appfw product <command>
scripts/appfw framework <command>
```

New docs, skills, prompts, and CI examples should link directly to the
quickstart or reference page instead of adding more content here.
