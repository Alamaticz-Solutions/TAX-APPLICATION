# Specs

This directory holds durable App Framework specs that need to outlive one chat,
branch, or PR description.

Use [Spec-Driven Change Harness](../start/spec-driven-change-harness.md) to
decide whether a change needs an intent note, lightweight spec, or full spec.
Use [Spec Template](spec-template.md) for new durable specs.

Keep this directory lean. Specs here should clarify business value, contracts,
decision provenance, risks, and acceptance evidence for framework or reusable
platform work. Product-specific specs normally belong in the product repo.
