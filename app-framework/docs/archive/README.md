# Documentation Archive

This directory contains historical implementation reviews, planning notes, and
design records. These files are useful context, but they are not the current
operating guide for App Framework.

Use live docs first:

```text
../README.md
docs/README.md
docs/start/cli.md
AGENTS.md
CLAUDE.md
.appfw/model/_specs/CONFIG_CONTRACT.md
```

Archived files may mention old paths, old generator behavior, fixed issues,
scratch SQL, redacted auth examples, or exploratory code. Before using archived
guidance, verify it against the current code and `scripts/appfw validate`.
