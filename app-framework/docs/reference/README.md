# Reference Contracts

Use this layer for stable product/framework contracts. These files answer what
is allowed, who owns it, and which artifact proves it.

| Contract | Guide |
| --- | --- |
| App topology manifest | [App Manifest](app-manifest.md) |
| Product/framework ownership | [Product Workspace Contract](product-workspace-contract.md), [Product Workspace Boundaries](product-workspace-boundaries.md) |
| Human-owned extension surface | [Product Extension API](product-extension-api.md) |
| Codegen package API | [Codegen API](codegen-api.md) |

CLI and generated ownership are in `docs/start/` because agents need them in
the first two minutes of almost every task.
